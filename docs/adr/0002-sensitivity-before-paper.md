# 敏感性分析层前置于论文层（启用时 L3 -> L5 -> L4）

原拓扑 L3 -> L4(论文) -> L5(敏感性) -> END 中，论文写在敏感性分析之前，最终交付物永远不含灵敏度分析章节，敏感性报告只是输出目录里的独立文件--启用 Layer 5 的价值大打折扣。我们决定：启用时改为 L3 -> L5 -> L4，PaperAgent 上下文中拿到敏感性报告，论文写入含真实数据的灵敏度分析章节；禁用时流程与现状完全一致（L3 -> L4 -> END）。

## Consequences

- 「五层」叙事从「收尾附加层」变为「论文前的条件插入层」，文档与架构描述需同步。
- Layer 5 以 Layer 3 的 results.json 为输入前提：求解层被跳过时，无论何种模式、何种决策，Layer 5 一律不可用。
- 敏感性分析层的跨层摘要进入论文层上下文，PaperManager 的评审范围隐含新增灵敏度章节。
